# 社内研修クイズアプリ(VR/アーケード業界知識テスト)

VR/アミューズメント業界の社内研修用クイズアプリです。単一HTMLファイルで完結し、外部ライブラリ・サーバー通信を一切使用しません。

## 使い方

`vr_quiz.html`(`index.html` も同内容)をブラウザで直接開くだけで動作します(インストール・ビルド不要)。

### GitHub Pagesで公開する場合

このリポジトリはGitHub Pagesでそのまま公開できます。

1. GitHubのリポジトリで「Settings」→「Pages」を開く
2. 「Build and deployment」の「Source」を `Deploy from a branch` に設定
3. 「Branch」を `main` / `/(root)` に設定して「Save」
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開される(ルートの `index.html` が自動的に開く)

1. 受験者名を入力して「はじめる」をクリック
2. 8分のカウントダウンが開始。各問題は4択形式(1正解+3ひっかけ)。リモートメンバーは口頭で回答し、該当する選択肢を代わりにクリックする(または曖昧な回答の場合は「△ 曖昧・一部正解(0.5点)」ボタンを使う)
3. 結果画面でスコア・正答率を確認し、印刷または目視で人事評価用に記録する
4. 間違えた問題は「復習する」から一覧確認・再挑戦できる

## ドキュメント

設計仕様・データの出典・拡張方法など、引き継ぎに必要な情報は [`docs/DESIGN.md`](docs/DESIGN.md) にまとめています。次回出題予定(HADO・リトプラ・ARゴジラ)の追加方法もこちらに記載しています。

## ファイル構成

```
vr_quiz.html                       … アプリ本体(単一HTML、これを開けば動く)
docs/DESIGN.md                     … 設計ドキュメントの索引(最初に読むファイル)
docs/DESIGN_v1_base_spec.md        … v1設計仕様(画面構成・状態遷移・採点/タイマー仕様の土台)
docs/DESIGN_v2_addendum.md         … v2追加仕様(4択化・ダークモード・サウンド・復習機能)
docs/HIKKAKE_CHOICES_SOURCE.md     … 全17問のひっかけ選択肢の原本データ
```
